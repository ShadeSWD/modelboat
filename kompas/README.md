# Макрос КОМПАС-3D: нативные модели по boat.json

Макрос `boat_kompas.py` строит по файлу `boat.json` из браузерного
конструктора сайта ([страница «Конструктор»](https://shadeswd.duckdns.org/boat/designer))
полноценные модели КОМПАС-3D — с деревом операций, которое можно править:

| Файл | Что это |
|---|---|
| `<имя>_корпус.m3d` | деталь корпуса: лофт («по сечениям») по 21 шпангоуту, оболочка толщиной `wall` с открытой палубой, отверстие под дейдвуд по линии вала |
| `<имя>_руль.m3d` | перо руля — скруглённая пластина `chord x span x thick` |
| `<имя>_дейдвуд.m3d` | дейдвудная труба (наружный d 6, канал 3,2 мм — правится константами в шапке макроса) |
| `nano.m3d`, `motor_130.m3d`, ... | болванки компонентов из `components`: параллелепипед или цилиндр |
| `<имя>_сборка.a3d` | сборка: корпус, руль, дейдвуд и все болванки на своих местах |

Все файлы сохраняются **рядом с boat.json**.

## Что нужно

* Windows и **КОМПАС-3D v20, v21 или v22** — подойдёт и учебная
  («КОМПАС-3D LT» не подойдёт: в нём нет API трёхмерных операций).
* Python 3 c пакетом `pywin32` — **или** встроенная в КОМПАС библиотека
  макросов («КОМПАС-Макро», меню *Приложения*), где pythonwin уже есть.

Установка pywin32 для системного Python:

```bat
pip install pywin32
```

## Порядок действий

1. На странице конструктора спроектируйте корпус и нажмите
   «Экспорт boat.json». Положите файл в удобный каталог
   (например, `C:\boat\boat.json`).
2. Запустите КОМПАС-3D (можно и не запускать — макрос запустит сам).
3. В командной строке:

   ```bat
   python boat_kompas.py C:\boat\boat.json
   ```

   Без аргумента макрос ищет `boat.json` рядом с самим собой.
   Из «КОМПАС-Макро»: *Приложения → КОМПАС-Макро → Редактор*, открыть
   `boat_kompas.py`, задать путь к json в переменной запуска и выполнить.
4. Макрос печатает ход построения по-русски; каждая деталь строится
   независимо, поэтому одна ошибка не срывает остальные. В конце — список
   того, что не построилось (если такое было).
5. Проверьте результат: откройте `<имя>_сборка.a3d`, включите МЦХ детали
   корпуса и сверьте объём с водоизмещением из конструктора — как это
   делать, расписано на [странице «КОМПАС-3D»](https://shadeswd.duckdns.org/boat/kompas)
   сайта.

Для пробы в каталоге лежит корректный пример `sample-boat.json`
(корпус 450 мм, комплект «классика», 21 шпангоут, 7 компонентов).

> Копии `boat_kompas.py` и `sample-boat.json` продублированы в
> `site/kompas/` — их раздаёт сам сайт (страница «КОМПАС-3D» ссылается на
> них для скачивания). Мастер — здесь, в `kompas/`; при правках макроса
> обновляйте копии: `cp kompas/boat_kompas.py kompas/sample-boat.json site/kompas/`.

## Честное предупреждение

Макрос написан по документации API7 (справочник `ksAPI7.chm` из SDK
КОМПАС) и **не прогонялся на живом КОМПАС** — не было Windows под рукой.
Имена отдельных интерфейсов между версиями SDK менялись, поэтому возможны
мелкие правки. Код разбит на независимые функции с комментариями — что
именно и через какие интерфейсы строится, — чтобы чинить было просто.
Наиболее вероятные места правок:

* `find_deck_face()` — перебор граней тела для «открытой палубы» оболочки
  (имена коллекций граней различаются между версиями). Обход: построить
  оболочку вручную — операция «Оболочка», толщина `wall`, удалить верхнюю
  грань;
* `add_spline()` — «Сплайн по точкам» (`Beziers` / `NurbsCurves`);
* коллекции операций `LoftedBosses` / `CutLofteds` / `ShellOperations` в
  `IModelContainer`;
* `IParts7.AddFromFile` и `IPlacement3D.InitByMatrix3D` при вставке в
  сборку.

## Система координат

Как в конструкторе: X — от транца к носу, Y — от диаметральной плоскости
на правый борт, Z — вверх от основной плоскости; всё в миллиметрах.
Эскизы шпангоутов лежат на плоскостях, параллельных YOZ, со смещением `x`
шпангоута; корпус и руль строятся сразу в судовых координатах, болванки
компонентов — с центром в начале координат детали и переносятся на место
матрицей размещения при вставке в сборку.
