# Модель судна для 3D-печати

Учебный сайт-практикум: полный путь к радиоуправляемой модели судна —
проектирование с честными расчётами (гидростатика, остойчивость, ходкость),
3D-печать корпуса, герметизация, электроника на Ардуино-совместимых платах
и управление с телефона по Bluetooth (пульт — прямо в браузере).

Прод: https://shadeswd.duckdns.org/boat/

## Состав

- `site/` — статический сайт (HTML/CSS/JS без сборки).
  - `assets/hull.js` — расчётное ядро: параметрические обводы
    (буксир / двухвальный катер / транспорт), численная гидростатика,
    равновесная посадка, ДСО наклонениями, ИТТК-57 + винт.
    Валидировано на корпусе Вигли (тест в `tests/`).
  - `assets/stl.js` — экспорт: бинарный STL (полая оболочка со стенкой),
    boat.json для КОМПАС-3D, CSV-таблица ординат.
  - `assets/boat.js` — конструктор: ведомость масс, компоновка
    с перетаскиванием, проверки, решение по шагам, чертёж.
  - `assets/parts.js` — база компонентов (платы, моторы, батареи…)
    с реальными массами и габаритами; два набора: «Микро» и «Классика».
- `arduino/` — прошивки: `micro_esp32c3` (BLE UART, два мотора),
  `classic_nano_hm10` (мотор + серво).
- `kompas/` — макрос КОМПАС-3D (API7): нативный лофт корпуса и сборка
  с болванками компонентов по boat.json.
- `deploy/` — docker compose (nginx:alpine, 127.0.0.1:8095).
- `tests/` — pytest: целостность страниц/ссылок/ассетов, синтаксис JS,
  численная валидация ядра.

## Запуск

```bash
cd deploy && docker compose up -d   # http://127.0.0.1:8095/
python3 -m pytest tests/ -v         # тесты (нужен node для --check)
```
